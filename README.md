# Node TypeScript Template

A clean and reusable Node.js + TypeScript template for quickly bootstrapping backend applications.

## Features

- TypeScript
- ESLint
- Prettier
- Path aliases
- Environment variables
- Hot reload (tsx / nodemon)
- Production build
- Source maps
- Strict TypeScript configuration
- Ready-to-use folder structure

## Project Structure

```
src/
├── config/
├── controllers/
├── middleware/
├── routes/
├── services/
├── utils/
├── types/
├── app.ts
└── server.ts
```

## Installation

```bash
git clone https://github.com/<username>/node-typescript-template.git

cd node-typescript-template

npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Production

```bash
npm start
```
